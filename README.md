# My Security Learning Pages

# Important Commands

```bash
# Cloning this repo incl. submodules
git clone --recurse-submodules git@github.com:schubertcs/security-learning.git

# Updating already checked out submodules
git submodule update --init --recursive

# Run and host website locally (as in production)
hugo server

# Run and host website locally (incl. draft pages)
hugo server -D

```
